# NOVA
<!-- impeccable:product-schema 1 -->
## Platform
android
## Stack
User-specified Kotlin and Jetpack Compose. Native smartphone HOME launcher.
## Product Purpose
A minimalist, customizable home for real installed applications, widgets, and local suggestions.
## Brand Commitments
NOVA; futuristic, premium, AMOLED and optional glass surfaces. Inspired by CleanYourTV's restraint.
## Capabilities and Constraints
Offline core; no root, accessibility interception, fabricated apps, or privileged setup. User-controlled default HOME role, usage consent and widget binding. Persistent pages, dock, folders, themes and portable backups.
## Accessibility
48dp controls, readable contrast, system font scaling, semantic labels and system animation preferences.
